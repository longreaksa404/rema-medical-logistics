# Section A - Response Design

### Phase 1 — Hours 0 to 24: Activate and Pre-Position

**Hours 0–3: Alert and Mobilize**

- Red Cross Operations Center receives trigger signal
- Emergency Coordinator activates
- All staging hub managers notified via phone/SMS
- Volunteer team leaders in each district put on standby
- Central warehouse team begins pulling pre-packed **Emergency Medical Kits (EMKs)**

**Hours 3–8: Load and Dispatch to Staging Hubs**

- Available trucks loaded at central warehouse
- Dispatched to all 3 staging hub
- Each hub receives
- Staging hub managers verify receipt and log inventory

**Hours 8–16: Hubs Receive Stock, Volunteers Deploy**

- Volunteer teams dispatched into neighborhoods on foot or motorbike
- Prioritize ****assessment
- Volunteers use a simple question paper form to identify:
    - household size
    - presence of elderly/pregnant/disabled persons
    - known chronic illness
    - current medication needs
- Forms returned to hub coordinator every 4 hours

**Hours 16–24: First Demand Is Assembled**

- Operations Center updates the REMA dashboard with district-level demand estimates
- Emergency Coordinator makes **reallocation decision**: does any hub need more stock before roads close further?
    - If yes → emergency resupply convoy dispatched before Hour 24

**Who Decides What in Phase 1**

| Decision | Decision-Maker | Constraint |
| --- | --- | --- |
| Activate REMA | Emergency Coordinator | Requires 2 of 3 triggers |
| Base stock allocation per hub | Pre-set formula (population-based) | No discretion — protocol only |
| Volunteer deployment zones | Hub Manager | Based on pre-mapped ward boundaries |
| Emergency reallocation at Hour 16–24 | Emergency Coordinator | Based on first demand report |
| Route changes if road blocked | Hub Manager | Notify Operations Center within 1 hour |

### Phase 2 — Hours 24 to 48: Deliver, Adapt, Sustain

**Last-Mile Delivery Modes (Phase 2)**

| Water Depth | Delivery Mode |
| --- | --- |
| 0–30 cm | Motorbike with waterproof pannier bags |
| 30–60 cm | Cargo bicycle or wading volunteer with backpack |
| 60–80 cm | Small motorized boat or inflatable raft |
| >80 cm | Delivery suspended; emergency radio contact only |

**Delivery Priority Order:** (detailed scoring is in Prioritization Framework Section)

- **Critical medical cases** — households with life-sustaining medication needs (insulin, heart medication, dialysis-adjacent supplies)
- **High-vulnerability households** — elderly alone, pregnant women, infants, people with disabilities
- **General households** — basic hygiene kits, ORS, wound care
- **Community collection points** — for households capable of self-collection

**Decision Authority Map**

```
OPERATIONS CENTER (Red Cross HQ)
│
│── Emergency Coordinator
│     Phase 1: All activation decisions
│     Phase 2: Resupply approvals, cross-district reallocation
│
└── 3× Hub Managers (one per district)
      Phase 1: Volunteer deployment, form collection
      Phase 2: Last-mile routing, adaptive delivery decisions
            │
            └── Volunteer Team Leaders (3–5 per hub)
                  Household assessment, direct delivery
                  Escalate safety issues to Hub Manager
```

**Information Flow Summary**

```
Volunteers → (paper forms every 4h) → Hub Manager
Hub Manager → (SMS/WhatsApp summary) → Operations Center
Operations Center → (dashboard update) → Emergency Coordinator
Emergency Coordinator → (resupply or reallocation order) → Hub Manager
```
